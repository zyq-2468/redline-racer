# 赤线 REDLINE 赛车小游戏

驾驶舱视角的 3D 赛车小游戏。驶过森林、海湾和峡谷，在连续弯道与路障之间寻找最佳路线，挑战更快的圈速与更干净的驾驶。

**[立即开始驾驶 ↗](https://zyq-2468.github.io/redline-racer/)**

## 游戏玩法

- **第一视角驾驶**：坐进朱红色赛车驾驶舱，体验加速、刹车、转弯和碰撞时的镜头反馈。
- **逐关挑战**：从森林环道出发，完成一圈即可解锁下一关，已通关的赛道可以反复挑战。
- **躲避路障**：绕过锥桶、轮胎组与隔离栏；冲出赛道会减速，碰撞会扣除驾驶质量分数。
- **刷新个人纪录**：每圈结束后查看圈速等级、驾驶质量和分段表现，找到下一圈的改进方向。
- **声音可选**：右上角开启引擎音，听到随加速变化的音调与碰撞反馈。

| 关卡 | 赛道 | 难度 | 风景与挑战 |
| --- | --- | --- | --- |
| 第 1 关 | 森林环道 · 1.93 km | 入门 | 林间缓坡、湖面与风车，熟悉驾驶节奏 |
| 第 2 关 | 海岸晴湾 · 2.35 km | 进阶 | 海湾连续弯、灯塔与礁石，练习控制入弯速度 |
| 第 3 关 | 落日峡谷 · 2.50 km | 挑战 | 赤岩、石拱与更紧的连续弯，挑战稳定走线 |

## 如何操作

推荐使用电脑浏览器与键盘。点击「开始驾驶」或按 Enter，倒计时结束即可出发。

| 按键 | 操作 |
| --- | --- |
| Enter | 开始驾驶 |
| W / ↑ | 加速 |
| S / ↓ | 刹车 |
| A、D / ←、→ | 左右转向 |
| Esc / P | 暂停或继续 |
| R | 重新开始本圈 |

**驾驶小提示**：直道加速，弯道前收油，必要时刹车；尽量留在路面上，保持连续干净驾驶。

关卡进度和个人最快圈速会保存在当前浏览器中，方便下次继续挑战。
